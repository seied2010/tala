کاتالوگ اختیاری شامل ۲۷ محصول و ۹ تصویر ساختگی برای نمایش فروشگاه طلا.

== Installation ==

۱. WooCommerce را فعال کنید.
۲. فایل ZIP افزونه را در بخش افزونه‌ها نصب و فعال کنید.
۳. از ووکامرس ← کاتالوگ نمونه طلا، دکمه ورود محصولات را بزنید.

قیمت، وزن، عیار، نام و موجودی همه محصولات ساختگی است. محصولات مانند کالاهای عادی WooCommerce قابل خرید هستند. دکمه حذف، فقط محصولات و تصاویر نشان‌گذاری‌شده توسط همین افزونه را حذف می‌کند.
