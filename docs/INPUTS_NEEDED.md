# ورودی‌های لازم برای فعال‌سازی واقعی

| ورودی | قابلیت وابسته | وضعیت بدون ورودی |
|---|---|---|
| هاست، دامنه، TLS، cron، بکاپ هر فروشگاه | استقرار و عملیات واقعی | آزمون محلی مستقل انجام می‌شود |
| برند، لوگو، عکس واقعی و WOFF2 مجاز | ظاهر نهایی و فونت اختصاصی | تصویر تزئینی/داده ساختگی و fallback |
| قواعد مالی تأییدشده، پایه مالیات و گردکردن | قیمت و فاکتور واقعی | تنظیمات امن؛ مقادیر تست توصیه مالی نیستند |
| افزونه/قرارداد درگاه منتخب و Sandbox واقعی | وصول/بازپرداخت بانکی | TEST ONLY؛ بدون انتقال وجه |
| API معتبر نرخ و کلید امن تست | نرخ خودکار زنده | نرخ دستی/استعلام و adapter تست |
| SMTP و SMS رسمی/Sender ID، سیاست OTP | تحویل واقعی اعلان و ورود پیامکی | صف ایمیل قابل آزمون؛ SMS/OTP غیرفعال |
| کالا، SKU، وزن، ویژگی و موجودی واقعی | فروش واقعی محصولات | شش گروه نمونه ساختگی |
| روش/هزینه/محدوده ارسال و سیاست مرجوعی | تحویل و پس از فروش | ورود مدیر و تأیید تنظیمات لازم است |
| OpenAPI آگاه، رزرو اتمیک واقعی، محیط تست و company/warehouse mapping | فروش آگاه‌محور | MOCK_ONLY؛ فروش متصل مسدود |
| حساب رسمی و مجوز API شبکه اجتماعی | انتشار خودکار اجتماعی | پیوندهای عادی؛ انتشار خودکار غیرفعال |
| محیط مرجع و بار/شبکه واقعی | SLA و Core Web Vitals میدانی | نتایج محلی و مصنوعی؛ بدون تضمین ظرفیت |

رمز و کلید را در چت یا اسناد عمومی نفرستید. از تنظیمات امن سرور استفاده کنید. مالکیت یا محل فیزیکی نگهداری طلا موضوع پرسش توسعه نیست؛ در اتصال آگاه تنها شناسه انبار منطقی مجاز لازم است.
